# gramado - Gramado OS

Fred Nora: gramado

# Main folders

```
admin/  - Administrator stuff

core/   - Gramado Core OS Components

docs/   - Documentation for Gramado 

gramde/ - Gramado Desktop Environment
        + Posix-like commands
        + Compositor / display server
        + Client-side GUI applications
        + 3D demo

tools/  - Gramado Tools 

```

# Usage

```
$ cd core/
$ make
```
