# gramado - Gramado OS

Fred Nora: gramado

# Main folders

```
admin/  - Administrator stuff
core/   - Gramado Core OS Components
docs/   - Documentation for Gramado 
tools/  - Gramado Tools 
winsys/ - Compositor and client-side GUI applications.
        - Posix-like commands
```

# Usage

```
$ cd core/
$ make
```
